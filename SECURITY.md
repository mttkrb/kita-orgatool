# Sicherheitslücken melden

Bitte keine öffentlichen Issues für Sicherheitslücken. Stattdessen privat melden über
**Security → Report a vulnerability** in diesem Repository.

Besonders interessiert uns alles, womit jemand ohne Orga-Passwort oder ohne persönlichen
Link Anmeldungen lesen oder ändern kann. Wer was darf, entscheiden die RLS-Policies in
`sql/`; der anonKey in den Seiten ist absichtlich öffentlich.

Das Tool wird ehrenamtlich betreut. Wir melden uns, sobald wir können.
